Documentation & installation

Everything needed to install the register on a campus server, connect the palm kiosk and run day-to-day operations.

Requirements Install on Windows Install on Linux / macOS Configuration (.env) Kiosk & palm bridge Owner workflow University admin workflow Backups & upgrades Troubleshooting Technology stack

Requirements

  • MySQL 8 or MariaDB 10.5+ (XAMPP works for pilots)
  • Node.js 18 or newer
  • A server or PC on the campus LAN, reachable on port 4000
  • For palm scanning: a Windows kiosk PC with the vendor palm SDK and the C++ bridge

Install on Windows

  1. Copy the mysql-app folder to the server machine and start MySQL.
  2. Run setup.bat once — it creates .env.
  3. Edit .env with your database credentials and owner login.
  4. Run setup.bat again — it creates the database, tables and owner account.
  5. Run start.bat and open http://localhost:4000/.

Allow Node.js through the Windows firewall so other machines can reach http://<server-ip>:4000.

Install on Linux / macOS

cd mysql-app
cp .env.example .env    # then edit it
npm install
npm run setup
npm start

A single consolidated schema lives in mysql-app/db/database.sql and is safe to re-run.

Kiosk & palm bridge

  1. Each university gets a kiosk URL: http://<server>:4000/kiosk/<slug>.
  2. Open it full-screen on the gate PC. Palm, RFID and manual entry are available as tabs.
  3. For palm vein, build the C++ bridge on the kiosk PC with the vendor SDK. Templates are matched locally and never leave that machine.
  4. The bridge posts the matched member code to POST /api/public/scan-event using the university's kiosk key.
  5. Rotating the kiosk key in the owner console invalidates the old key immediately — update every bridge.

Owner workflow

  1. Sign in at /login with the owner account.
  2. Provision access — create the university, its kiosk slug and subscription window, then issue the first admin login.
  3. Plans and Payments — packages, member limits, invoices, collections and dues.
  4. Leads (CRM) — enquiries from the public contact form arrive here and can be converted into a university.
  5. Website — brand the public pages, or replace the home and contact pages with your own HTML/CSS.
  6. The owner console is a business console: it cannot open any campus's members, scans or reports.

University admin workflow

  1. Add members manually or bulk-import from Excel/CSV; maintain courses, departments and years under Master data.
  2. Enrol palm templates or RFID cards per member, and upload photos for on-screen verification.
  3. Watch live occupancy on the dashboard; footfall by hour, department and gender.
  4. Use Reports with the calendar, pick the columns you want, then print or export to Excel, CSV or PDF.
  5. Customise the kiosk with the university name, logo and colours under Settings.

Backups & upgrades

mysqldump -u root -p library_register > backup-YYYYMMDD.sql
mysql -u root -p library_register < backup-YYYYMMDD.sql

To upgrade: back up, copy the new files, run npm install and restart. New tables and columns are applied automatically on boot.

Troubleshooting

SymptomFix
Admin cannot sign inCheck the account is Active and the subscription is current; reset the password from the owner console
Kiosk says "not allowed"Subscription expired or the university is suspended
Bridge gets 401The kiosk key was rotated — update KIOSK_KEY on the kiosk PC
No emailsCheck SMTP host, port and credentials in System settings
Server won't startMySQL not running, or wrong DB_PASSWORD in .env
